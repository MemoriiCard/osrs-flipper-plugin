OSRS Flipper beta
=================

1. Install Java 11 or newer: Temurin 17 from https://adoptium.net (default options).
2. Jagex Account? Once: open "RuneLite (configure)", add --insecure-write-credentials to
   Client arguments, Save, then start RuneLite from the Jagex Launcher once and close it.
3. Double-click "Start OSRS Flipper Beta".
   Mac/Linux: run  java -ea -jar osrs-flipper-beta.jar  in this folder.
4. Open the OSRS Flipper panel on RuneLite's sidebar, read the data notice, and click
   "Agree & sign in".

The full tester guide is on the website's Download page.
